# Planned by Jay

Next.js homepage, reusable foundations and a three-stage holiday enquiry page. No booking engine or customer authentication. Submissions remain disabled until configured and approved.

Run `npm ci`, then `npm run dev` and visit http://localhost:3000.

Start with [the owner's guide](docs/WEBSITE-GUIDE.md), [enquiry setup](docs/ENQUIRY-SETUP.md) and [design system](docs/DESIGN-SYSTEM.md). View the brief at http://localhost:3000/plan-my-holiday. Use `npm test`, `npm run lint`, `npm run typecheck` and `npm run build` for checks. This is a development site with contact, legal, portrait and policy placeholders; search indexing is disabled until launch. Supabase/Resend credentials, scheduler, genuine delivery tests and live approval are still required.
